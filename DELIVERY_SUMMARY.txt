                           API ENDPOINTS
================================================================================

AUTHENTICATION (2 endpoints)
============================
POST   /api/auth/register        - User registration
POST   /api/auth/login           - User authentication

STUDENTS (5 endpoints)
======================
GET    /api/students             - List all students
GET    /api/students/:id         - Get student by ID
POST   /api/students             - Register new student (Admin/Instructor)
PATCH  /api/students/:id         - Update student (Admin/Instructor)
DELETE /api/students/:id         - Delete student (Admin)

ENROLLMENTS (6 endpoints)
=========================
GET    /api/enrollments          - List all enrollments
GET    /api/enrollments/student/:id - Get student enrollments
POST   /api/enrollments          - Create enrollment (Admin/Instructor)
PATCH  /api/enrollments/:id      - Update enrollment (Admin/Instructor)
POST   /api/enrollments/:id/drop - Drop course
DELETE /api/enrollments/:id      - Delete enrollment

REPORTS (3 endpoints)
=====================
GET    /api/reports/performance  - Performance analytics
GET    /api/reports/department/:dept - Department statistics
GET    /api/reports/enrollment/stats - Enrollment statistics

HOTEL MANAGEMENT (7 endpoints)
==============================
GET    /api/hotel/rooms/available - Available rooms
GET    /api/hotel/rooms           - All rooms (Admin/Staff)
POST   /api/hotel/rooms           - Create room (Admin/Staff)
GET    /api/hotel/bookings        - All bookings (Admin/Staff)
POST   /api/hotel/bookings        - Create booking
POST   /api/hotel/bookings/:id/checkin - Check-in (Admin/Staff)
POST   /api/hotel/bookings/:id/checkout - Check-out (Admin/Staff)

TASKS (7 endpoints)
===================
GET    /api/tasks                 - List tasks
GET    /api/tasks/:id             - Get task details
POST   /api/tasks                 - Create task
PATCH  /api/tasks/:id             - Update task
POST   /api/tasks/:id/comments    - Add comment
POST   /api/tasks/:id/assign      - Assign task
DELETE /api/tasks/:id             - Delete task (Admin)
